# 千问录音转 VTT

这个 Chrome 本地扩展直接读取千问录音纪要分享页中的转写、发言人和时间戳，在浏览器本地生成 WebVTT 文件。转写正文不会发给模型或第三方服务。

## 安装

1. 在 Chrome 打开 `chrome://extensions`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录：`tools/qianwen-vtt-exporter`。

## 使用

1. 打开一个千问录音纪要分享链接，切换到“转写”。
2. 点击页面右下角的“导出 VTT”。
3. 在保存窗口中选择项目的 `data/education/transcripts` 目录。

工具会将每一段的结束时间设为下一段的开始时间。最后一段优先使用播放器显示的录音总时长；如果页面没有提供总时长，则使用“最后一段开始时间 + 5 秒”。
