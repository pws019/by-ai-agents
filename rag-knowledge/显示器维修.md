# 显示器维修知识

## 场景：显示器提示无信号怎么办？
**可能原因**：
1. 信号线松动：HDMI、DP、VGA 或 Type-C 线未插紧。
2. 输入源选择错误：显示器当前输入源与实际接口不一致。
3. 电脑未输出画面：主机未开机、休眠或显卡输出异常。
4. 线材不支持显示输出：部分 Type-C 线只支持充电或数据传输。

**排查与维修步骤**：
1. 确认主机已开机，键盘 Num Lock 指示灯能正常切换。
2. 重新插拔显示器和电脑两端的信号线，确认接口插紧。
3. 在显示器菜单中手动选择正确输入源，如 HDMI、DP 或 Type-C。
4. 更换一根信号线或换一个电脑输出接口测试。
5. Type-C 连接时，确认电脑接口支持视频输出，线材支持 DP Alt Mode 或雷电显示输出。

## 场景：显示器黑屏但电源灯亮怎么办？
**可能原因**：
1. 显示器有电但没有接收到有效信号。
2. 亮度或对比度被调得过低。
3. 电脑进入睡眠或显卡驱动异常。
4. 背光、电源板或主板故障。

**排查与维修步骤**：
1. 按显示器菜单键，观察 OSD 菜单是否能显示。
2. 如果菜单能显示，优先检查输入源、信号线和电脑输出。
3. 调高亮度和对比度，恢复显示器图像设置。
4. 重启电脑，或连接另一台电脑测试显示器。
5. 如果菜单也无法显示，但电源灯正常，可能是显示器内部背光或主板故障，应联系专业维修人员。

## 场景：显示器电源灯不亮怎么办？
**可能原因**：
1. 插座无电或电源适配器未插紧。
2. 电源线、适配器或插排损坏。
3. 显示器电源按键未打开。
4. 显示器电源板故障。

**排查与维修步骤**：
1. 换一个已确认有电的插座测试。
2. 检查电源线和适配器接口是否插紧。
3. 如果显示器有独立电源开关，确认开关处于开启状态。
4. 更换同规格电源线或适配器测试。
5. 如果仍无电源指示灯，应联系专业维修人员检查电源板。

## 场景：显示器画面闪烁怎么办？
**可能原因**：
1. 刷新率设置不合适。
2. 信号线接触不良或质量不足。
3. 显卡驱动异常。
4. 电源干扰或显示器背光故障。

**排查与维修步骤**：
1. 在电脑显示设置中选择显示器支持的推荐刷新率。
2. 重新插拔信号线，尽量使用显示器原装线材。
3. 更换 HDMI、DP 或 Type-C 线测试。
4. 更新或重装显卡驱动。
5. 如果连接不同电脑仍闪烁，可能是显示器背光或电源板问题，应联系专业维修人员。

## 场景：显示器画面有横线、竖线或花屏怎么办？
**可能原因**：
1. 信号线接触不良或接口氧化。
2. 显卡输出异常。
3. 分辨率或刷新率设置超出显示器支持范围。
4. 面板、排线或驱动板故障。

**排查与维修步骤**：
1. 重新插拔信号线，检查接口针脚是否弯曲、脏污或损坏。
2. 换线、换接口或换电脑测试，判断问题在显示器还是电脑。
3. 将分辨率和刷新率改为显示器推荐值。
4. 如果 OSD 菜单本身也有线条或花屏，说明更可能是显示器内部故障。
5. 固定位置的亮线、暗线或大面积花屏通常需要专业维修或更换面板。

## 场景：显示器 Type-C 连接没有画面怎么办？
**可能原因**：
1. Type-C 线不支持视频输出。
2. 电脑 Type-C 接口不支持 DP Alt Mode 或雷电协议。
3. 使用了扩展坞、转接头或延长线导致信号异常。
4. 显示器输入源未切换到 Type-C。

**排查与维修步骤**：
1. 确认电脑 Type-C 接口规格，必须支持视频输出。
2. 使用支持视频输出的 Type-C 线，优先使用显示器原装线。
3. 暂时移除扩展坞、转接头和延长线，直接连接电脑与显示器。
4. 在显示器菜单中选择 Type-C 输入源。
5. 如果仍无画面，换一台支持 Type-C 视频输出的电脑测试，判断是电脑接口、线材还是显示器问题。
