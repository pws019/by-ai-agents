# 学习范围、独立练习与验收

## 1. 目的与完成口径

本文件保证业务范围收敛不变成学习内容缩水。实现通过 T/AC 验收；学习通过 L 验收。两者独立记录，不要求一开始就能独立写整个系统。

- 做出来：代码可运行，测试和演示通过，可以由 Claude 主导。
- 讲明白：学习者结合真实代码解释调用路径、数据来源、失败点及设计取舍。
- 独立改：学习者可查文档，但在 Claude 不代写的情况下完成限定改动或诊断，提供验证证据。

所有 L 项要求讲明白，并完成对应独立练习。练习使用开发数据库、合成数据和隔离分支，不触及生产。若由 Claude 代做，标记已演示，后续换一个等价案例独立复现。
独立通过依据学习者实际提交的代码、操作记录或回答，不由 Claude 凭感觉判定。用户可以选择先推进实现，学习欠项仍保留。

## 3. 分阶段学习验收

### L-00：从 Web 请求到 Agent 执行（M0）

讲明白：Python async/await 与服务边界；模型、工具、编排的区别；State/Node/Edge、checkpoint、interrupt；HTTP 连接断开与任务状态的区别。
独立练习：给 spike 增加一个“缺少原因则等待补充”的分支；暂停后重启服务再恢复，并说明哪些代码重执行。
证据：代码差异、重启前后同一任务标识、测试结果和调用图。内存存储不能作为重启恢复证据。

### L-01：业务事实与权限（M1）

讲明白：课程/版本/班期、订单与报名；认证和资源授权；为什么 userId 不能由模型决定。
独立练习：增加一个新的合成班期及学员权益样例，演示本人访问成功、另一学员访问失败；追踪可信身份如何传到工具。
证据：seed 改动、两种请求结果、权限检查代码位置。能指出前端隐藏按钮不足以保护数据。

### L-02：让业务写操作可靠（M2）

讲明白：草稿、确认、revision、事务、幂等键、业务唯一约束的不同作用；批准和执行完成的区别。
独立练习：在开发测试中复现同申请并发审批及旧确认卡提交；先预测结果再运行，并定位保护机制。补一个尚未覆盖的状态冲突测试。
证据：失败请求、数据库终态、唯一审计结果和新增测试；不能只说“加锁就好了”。

### L-03：工具、多轮任务与人工协作（M3）

讲明白：LLM 产生工具调用、后端执行工具、结果回传的完整循环；schema 校验与授权区别；聊天记忆/任务状态/业务事实；重试与预算；人工接管。
独立练习：给现有查询能力增加一个只读工具或字段，从契约到 UI 打通；随后复现一次工具超时和一次待确认恢复，验证不重复提交。
证据：契约/工具/测试改动、一条完整 trace、恢复后的申请数；解释为何不能给学生 Agent 审批工具。

### L-04：检索质量与来源（M4）

讲明白：Embedding、切块、召回、重排各解决什么；Recall@K 不等于回答正确率；阈值不是置信概率；版本过滤和访问授权。
独立练习：选择一个失败检索问题，先判定是没召回、排序错误还是生成无依据，再只改变一个变量（切块、候选数或重排）做对照。更新一份字幕并确认旧片段失效。
证据：固定案例、候选与引用、前后指标/耗时、旧版本检查。至少包含纯向量与当前重排对照，不要求新方案必胜。

### L-05：图谱真实解决什么（M5）

讲明白：实体、边方向、别名、两跳查询、循环检查；关系来源审核；Neo4j 与关系表取舍；图与向量投影一致性。
独立练习：独立录入一组来自示例课程的先修关系，编写或修改参数化查询；测试有关系、无关系、存在外班期片段三种输入。
证据：查询、结果、审核来源、权限测试；比较纯 RAG 与图谱组合，解释关系查到了却没有本期回放时怎么回答。

### L-06：微调实验而非只跑训练（M6a）

讲明白：SFT、LoRA 与量化各起什么作用；rank/alpha、学习率、序列长度的作用；显存、训练损失与过拟合；工具模板及数据泄漏；训练量化不代表推理必然采用相同精度。
独立练习：人工核验一组训练样本，找出动态事实记忆/格式错误/重复模板问题；写清数据划分与三组对照配置，分析至少一个改善和一个未改善或退化案例（按实际结果）。
证据：数据修订、split 清单、配置、真实日志和结果。能解释 loss 下降为什么不足以证明业务收益；没有 GPU 运行时只通过准备部分，真实实验保留待完成。

### L-07：故障定位与性能（M6b）

讲明白：首字与总耗时、P50/P95、并发与排队；trace 与业务审计区别；为什么工具超时不代表未执行。
独立练习：选择模型慢、图数据库不可用、写入成功后连接超时中的两个故障，用开发环境复现；从 requestId 定位瓶颈或不确定结果并验证降级/核验。
证据：故障设置、trace、数据库结果、恢复步骤。负载结果必须注明硬件、并发、模型和样本量，不将一次快响应当作性能结论。

### L-08：独立修改与面试表达（M6c）

讲明白：10 分钟讲清业务、架构、一个正常闭环、一个失败案例、实验收益及局限。
独立练习：从现有能力选一个小需求，例如新增申请查询过滤条件或回放卡片字段，独立修改契约、实现和必要测试；无需重新开发整套系统。
证据：可运行修改、测试结果、三项设计取舍（LangGraph 迁移、业务确认边界、图谱与 RAG 分工）。能够说明哪些数据是合成、哪些实验是真实、哪些能力尚未上线。
